## 3. Scope of Service

### 3.1 What is Included

The security audit covers the **single domain** (and its subdomains, for Professional and Agency tiers) specified at order submission. The scope is limited to:
- Publicly accessible HTTP/HTTPS endpoints
- DNS records and infrastructure associated with the specified domain
- For authenticated testing (Professional/Agency): only the accounts and roles you explicitly provide credentials for

### 3.2 What is Excluded

The following are **out of scope** and will not be tested:
- Any domain, IP address, or service not explicitly listed in the order
- Third-party services hosted at subdomains you do not control (e.g. a Salesforce subdomain)
- Physical security, social engineering, or phishing
- Denial of service (DoS/DDoS) testing of any kind

### 3.3 Scope Verification

Before any active scanning begins, EchoForge verifies domain ownership via a DNS TXT record (`_echoforge-verify.{domain}`). This is a non-negotiable requirement. No scan will proceed without successful scope verification or a manually approved authorisation letter.

## 4. Data Handling & Retention

### 4.1 Data Collected During the Scan

The scan will access and process:
- Publicly accessible HTTP responses, headers, and cookies
- DNS records associated with your domain
- TLS certificate data
- Content of exposed paths if any are discovered

### 4.2 Data We Store

- **Findings JSON** — structured vulnerability data stored in our database for report generation
- **PDF report** — stored in Google Drive for 30 days after delivery, then permanently deleted
- **Raw scan output** — stored in our work directory for the duration of the scan only, then deleted on completion

### 4.3 Data Retention Policy

| Data Type | Retention Period |
|---|---|
| Findings JSON (database) | 90 days from delivery |
| PDF report (Google Drive) | 30 days from delivery |
| Raw scan artifacts | Deleted on scan completion |
| Audit metadata (order ID, domain, timestamp) | 12 months |

After the retention period, all associated data is permanently deleted. EchoForge does not sell, share, or transfer your scan data to any third party.

### 4.4 Credentials (Authenticated Testing)

For Professional and Agency tier orders requiring authenticated testing:
- Login credentials are used solely for the duration of the authenticated scan phase
- Credentials are not stored in plaintext after scan completion
- We strongly recommend creating a **dedicated test account** with limited permissions for this purpose
- Credentials should be rotated after the scan is complete

## 6. Rules of Engagement

### 6.1 Permitted Activities (during an active scan)

- Passive DNS and certificate transparency queries
- HTTP/HTTPS requests to endpoints on the specified domain
- TLS handshakes to assess certificate and cipher configuration
- CORS origin reflection tests
- HTTP security header analysis
- Cookie attribute analysis
- For Professional/Agency: authenticated browser sessions using the credentials you provide

### 6.2 Prohibited Activities (we will never do these)

- Denial of service attacks (SYN floods, HTTP floods, resource exhaustion)
- Destructive operations (deleting data, modifying database records, dropping tables)
- Exfiltrating or retaining any customer data found during the scan (only metadata is recorded)
- Accessing systems outside the defined scope
- Brute-force attacks against authentication systems beyond standard credential stuffing checks
- Physical intrusion or social engineering

### 6.3 Critical Finding Protocol

If the scan discovers an actively exploitable critical vulnerability (e.g. unauthenticated remote code execution, exposed database with customer data):

1. We will **pause the scan immediately** after confirming the finding
2. We will **notify you by email within 1 hour** of discovery — do not wait for the review gate
3. We will **not include raw exploit payloads** in the report if they could cause harm if the report is accessed by unauthorised parties
4. We will advise immediate remediation before the report is delivered to any third party
